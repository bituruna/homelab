# Homelab — Arch Linux em hardware legado

> Laboratório pessoal de infraestrutura construído em um Acer Aspire 4636Z
> (Pentium T4400, 3 GB RAM), documentado como um ambiente de produção.

## Objetivo
Desenvolver e evidenciar competências em administração Linux, redes, bancos de
dados, monitoramento e segurança defensiva, operando serviços reais em hardware restrito.

## Hardware
| Componente | Especificação |
|---|---|
| Modelo | Acer Aspire 4636Z |
| CPU | Intel Pentium Dual-Core T4400 (2 núcleos, 2,2 GHz) |
| RAM | 3 GB |
| Disco | HD 150 GB (tabela MBR, BIOS Legacy) |
| SO | Arch Linux + XFCE |

## Estrutura do repositório
| Diretório | Conteúdo |
|---|---|
| `docs/` | Documentação por módulo, ADRs e diagramas |
| `inventory/` | Inventário de hardware, serviços e usuários |
| `configs/` | Configurações sanitizadas |
| `scripts/` | Scripts de administração |
| `runbooks/` | Procedimentos operacionais |
